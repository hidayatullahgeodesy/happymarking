# happymarking

An interactive web-based Geospatial Editor and Navigator designed for mission planning and tactical visualization.

## 🚀 Features
- **Tactical Night Mode**: Enhanced visibility for low-light operations.
- **KML/GPX Integration**: Import and export mission data effortlessly.
- **Interactive Storytelling**: Step-by-step mission bab navigation with Next/Prev controls.
- **Elevation Intelligence**: Real-time altitude profiling with map synchronization.
- **Intel Table**: Organized asset management for Story Points and Waypoints.

## 🛠️ Tech Stack
- Leaflet.js (Mapping Engine)
- Geoman (Geometry Editor)
- Chart.js (Data Visualization)

## 📖 How to Use
1. Open `index.html` in any modern web browser.
2. Use the **Ops Toolbar** to draw points or routes.
3. Import existing GPX data via the **GPX button**.
4. Export your final mission plan as a **Tactical Story Map**.
